01

The app.

This is StreamVault itself, served by the cluster at localhost:30080. The badge at the top right names the pod that answered. Upload, search, play, download and delete all work.

02

One stream.

The browser asks for byte ranges. NGINX hands each range to an API pod, the pod reads it out of MongoDB GridFS and answers 206 Partial Content. Seek the video and watch new ranges arrive.

    04

    One URL, many pods.

    Fire a burst of requests at localhost:30080. NGINX re-resolves the headless service every five seconds and spreads requests over every ready API pod.

    05

    It grows.

    Start a real load test: 120 connections streaming 256 KB ranges. The HorizontalPodAutoscaler watches CPU against a 60 percent target and adds API pods, up to twelve.
